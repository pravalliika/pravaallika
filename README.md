## 🚀 Featured Projects
 
### 🛒 [Kubernetes Ecommerce Microservices CI/CD](https://github.com/pravalliika/k8s-ecommerce-microservices-cicd)
> End-to-end microservices ecommerce app deployed on **AWS EKS** with full GitOps pipeline
 
- **CI:** GitHub Actions → Docker build → push to Amazon ECR
- **CD:** ArgoCD watches Git repo → auto-deploys to EKS
- **Infrastructure:** EKS cluster provisioned via **Terraform**
- **Routing:** Ingress-Nginx as ingress controller
- **Database:** AWS RDS (MariaDB)
- **Logging:** EFK Stack (Elasticsearch + Fluent Bit + Kibana)
- **Monitoring:** Grafana + Prometheus dashboards
- `Kubernetes` `EKS` `ArgoCD` `GitHub Actions` `Terraform` `Docker` `Grafana`
---
 
### 📊 [AWS Log Analytics — CloudWatch, CloudTrail & Athena](https://github.com/pravalliika/aws-log-analytics-cloudwatch-athena)
> Serverless log analytics pipeline: collect → store → query AWS logs with SQL
 
- **EC2 logs** collected via CloudWatch Agent from `/var/log/*`
- **CloudTrail** captures all AWS API calls and account activity
- Logs exported and stored in **Amazon S3**
- **Amazon Athena** queries logs using standard SQL — no servers needed
- Detects failed API calls, S3 access events, EC2 errors, IAM activity
- `CloudWatch` `CloudTrail` `Athena` `S3` `IAM` `EC2` `Serverless`
